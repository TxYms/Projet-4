# DataShare : front Angular

Voir le [README principal](../README.md) pour l'installation complète.

| Commande | Rôle |
|---|---|
| `npm start` | Serveur de développement sur http://localhost:4200 (les appels `/api` sont relayés vers l'API sur le port 8080) |
| `npm run build` | Build de production dans `dist/frontend/browser` |
| `npm run test:ci` | Tests unitaires et couverture |
| `npm run e2e` | Tests de bout en bout Playwright (API et front lancés) |
